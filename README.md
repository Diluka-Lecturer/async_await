# Flutter Async/Await Lab

Welcome to the Flutter Async/Await practice lab! In this exercise, you will learn how to handle asynchronous operations using `Future`, `async`, and `await`.

## 🚀 Getting Started

1. Clone this repository to your local machine.
2. Run `flutter pub get` to ensure all dependencies are fetched.
3. Open the project in your IDE.
